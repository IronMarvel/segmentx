# Design diagrams

Rendered PNGs are provided for the report. The `.dot` Graphviz source files are retained so the diagrams can be edited and regenerated.

- `architecture.dot/png` - system architecture
- `workflow.dot/png` - end-to-end process flow
- `use_case.dot/png` - user/system interactions
- `sequence.dot/png` - key execution sequence
- `class_diagram.dot/png` - implementation module/class relationships
